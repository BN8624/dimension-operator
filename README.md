# 《차원관리사업부》 / 《디멘션 오퍼레이터》 (가칭)

현대 SF 판타지 웹소설 집필 저장소입니다. 제목, 인물명, 기업명은 모두 가칭입니다.

**리더로 읽기:** https://bn8624.github.io/dimension-operator/ (GitHub Pages를 켠 뒤부터 열립니다)

저장소 루트의 `index.html`이 리더입니다. `episodes/`, `docs/`, `changelog/`, `archive/`의 md 파일을 자동으로 찾아 회차별 최신 판을 보여 줍니다. 새 판을 올리면 별도 작업 없이 반영됩니다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `episodes/` | 회차 원고 (최신 판) |
| `docs/` | 기획안(`PROJECT_PLAN`)과 회차별 상태 기록(`STORY_STATE`) |
| `changelog/` | 판본별 수정 기록 |
| `archive/` | 이전 판 문서 |

## 현재 기준 판

- 원고: 1화 v0.5, 2화 v0.3, 3화 v0.4, 4화 v0.2
- 기획안: v0.9 (톤 원칙 추가)
- 상태 기록: 1~2화 `STORY_STATE_002_v0.4`, 3화 `STORY_STATE_003_v0.4`, 4화 `STORY_STATE_004_v0.2`

## 문서 원칙

- 기획안에는 바뀌지 않는 원칙과 설정, 앞으로의 회차 설계만 둡니다.
- 작성된 회차에서 일어난 사실은 `STORY_STATE`에만 기록하며, 원고에 쓰인 단계까지만 적습니다.
- 수정 이유는 `changelog/`에 남깁니다.
- 원고는 가볍게 씁니다. 정확한 사실 관계는 `STORY_STATE`가 맡습니다(기획안 1-1 톤 원칙).
