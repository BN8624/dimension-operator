# 3·4화 톤·설정 단순화 기록 v0.2

## 배경

사용자 검토: "스토리가 너무 딥하다." 분위기가 무겁고(실패·반성·진지함) 설정이 복잡하다(원반·모듈·목록·관할)는 두 가지 모두에 해당한다.

검토를 거듭하며 정합성 지적을 원고 안에서 하나씩 해결하다 보니 절차, 단서 조항, "아직 모른다"가 쌓였다. 3화는 절차 단어 밀도가 1화보다 30% 높았고, 4화는 웃음 묘사가 0이었다. 3~4화 두 화 연속으로 보상 없이 끝났다.

원칙: **설정의 정확성은 STORY_STATE가 맡고, 원고는 가볍게 간다.**

## 1. 설정 단순화

| 남긴 것 | 원고에서 뺀 것 (사건에서 없어진 것으로 본다) |
|---|---|
| 폭주 직전 0.8초 계측 공백 + 근처 화면 정지 | 결측·하강 구분, 시각 필드, 동작 구분 |
| 은색 장치와 인증 홈 → 업계 누군가의 장비 | 제조 계열·세부 모델, 등록기관 조회 절차 |
| 원반 = 장치를 지우는 리모컨 | 원반 연결 목록 2건, 목록 순번, 기준 시점, 발신원 후보 순위 |
| 현지 경찰 협조 | 요청서 항목, 공유 범위·훼손 책임·분석 순서 협상 |
| 접근자 묵비 | 감사 인계·경위서 접수 알림 |
| 2호 장치의 온전한 기록 | 수신 방향 기록, 재가동 초기화 표시 |

## 2. 3화 (v0.3 → v0.4, 크게 다시 씀)

- 세라핀 정비실 장면은 그대로 두었다.
- 보고서 결재는 서지안의 한 줄("감점은 숨겼을 때 받는 거예요")로 끝냈다.
- 요청서 반려를 코미디로 바꿨다("‘다 주세요’는 요청이 아니라 협박이에요").
- 백소연과의 화상 협의를 3분짜리로 줄였다. 백소연이 요청서가 두 번째 판인 걸 알아보는 장면을 넣었다.
- 장치 검사: 붉은빛 = 스스로 지우던 중, 루미엘의 한 발로 40%에서 멈춤, 남은 신호 수신 1건.
- 원반 기록: 교전 중 1회 사용, 폭주 시각 기록 없음 → "지우는 리모컨". 서지안의 "아직은 ‘아마’" 한마디만 단서로 남겼다.
- **중심을 화면 정지 추리로 옮겼다.** 서지안이 분석 기여란에 태오의 이름을 직접 적는 승리로 끝난다.
- 3조 채널 잡담을 추가했다(세라핀 밥, 아리아 "세라핀.").
- 편성 조건은 서지안의 두 줄과 한마디로 처리했다. 일정 변경 전달 담당은 계속 비워 두었다(4화의 원인).

## 3. 4화 (v0.1 → v0.2)

**이전 검토 지적 반영**
- 아리아가 하지 않은 말을 했다고 하던 부분: "문 연구원님이 주차장에 남는 건 저도 알았습니다"로 고쳤다.
- 태오의 자백 범위: 시험의 존재와 앞당김을 모두 들었다고 인정한다. 문채령의 "상태 바뀌기 전에 불러 달라"를 태오가 "장치가 보이면"으로 들은 오해를 회의에서 드러냈다.
- 마트 장치 전원: 표시판 전원에 물려 있었고(1호는 자체 전지), 정전 뒤 꺼져 있던 사흘 전 기록이 재기동으로 지워졌다고 밝혔다.
- 장치가 빛날 때 태오가 계측을 확인한다(공백·폭주 반응 없음). 덮개 낙하 원인(열)도 넣었다.
- '작업표'는 시설의 종이 작업표, 태오 쪽은 '화면 메모'로 구별했다.
- 손실 범위를 "사흘 전 기록을 잃었다"로 정리했다.
- 27·35·71행 어색한 표현, 237·261행의 모호한 동작을 고치거나 뺐다. 139행처럼 서술자가 결말을 미리 말하는 부분도 뺐다.

**톤**
- 주차장 장치를 기록이 온전한 채로 확보한다(승리).
- 마트 사고를 짧은 액션으로 바꿨다. 세라핀이 좁은 방호막으로 직원을 지키고, 고출력은 쓰지 않는다.
- 회의를 절반으로 줄였다. 끝에 세라핀의 한마디("칭찬은 나중에")로 숨을 돌린다.
- 반전 결말: 세라핀 손목 카메라 영상 속 **[설치·점검: 다온설비]** 스티커. 마트 표시판 업체이면서 네오아크 지정 협력사다.
